# Presentación de Sport Center

## Abrir

1. Descomprime `demo-reservas-sport-center.zip`.
2. Abre la carpeta y haz doble clic en `index.html`.
3. Para mostrar el panel, pulsa **Administración** e ingresa `admin@sportcenterrengo.cl` / `admin123`.

La demo guarda datos en el navegador de ese computador. Para enseñarla desde otro equipo hay que copiar el archivo ZIP y abrirlo allí; las cuentas y reservas no se sincronizan. La versión arranca con las estadísticas vacías, como pediste.

## Recorrido sugerido

1. Muestra el inicio, las fotos del club, los precios y la opción **Reservar cancha**.
2. Crea una cuenta de prueba con un correo y RUT válidos.
3. Reserva una fecha, horario y cancha disponibles. El cobro de la cancha se registra después de jugar, en Administración.
4. En Administración, agrega inventario, crea una reserva, registra un consumo y muestra cómo se asignan puntos y saldos.
5. Muestra **Añadir resultado** en una reserva cuyo partido ya haya terminado.

Los datos de esta computadora ya podrían incluir cambios hechos durante pruebas anteriores. No uses **Reiniciar demo** antes de respaldarlos: esa acción borra los datos guardados en ese navegador.

## Alcance actual

Es una demo local para presentar el diseño y probar los flujos. No publica reservas al club, no sincroniza cuentas entre clientes y no envía confirmaciones automáticamente. El pago se registra en el club después del partido. Para abrirla a clientes reales falta conectar una base de datos y autenticación seguras, integrar el correo del club y publicarla bajo una dirección web estable.

El acceso de administración incluido es solo para la demostración. No lo uses para administrar información real ni compartas copias del navegador que contengan datos de clientes.
